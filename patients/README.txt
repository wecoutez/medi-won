medi-won.com/patients 배포용

1. 병원 사이트 저장소(medi-won-FINAL 구조) 루트에 이 patients 폴더를 통째로 복사
2. git add patients && git commit -m "add patients demo" && git push
3. 1~2분 뒤 https://www.medi-won.com/patients/ 에서 열림

- 사이트 메뉴 어디에도 링크하지 않았고, noindex라 검색에 안 잡힙니다.
- 화면 맨 위에 "데모 화면입니다" 띠가 있습니다. 빼려면 index.html에서 demo-ribbon 부분을 지우면 됩니다.
